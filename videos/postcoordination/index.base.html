Two ways to express meaning
PRECOORDINATED
“A precoordinated expression includes a single concept.”
31978002 |Fracture of tibia|
POSTCOORDINATED
Combines multiple concepts based on SNOMED CT rules — so detail can be recorded without creating a new concept.
31978002 : … = …
Building an expression
“Fracture of the left tibia”
31978002 |Fracture of tibia| :
  363698007 |Finding site| =
  ( 12611008 |Bone structure of tibia| :
    272741003 |Laterality| =
    7771000 |Left| )
1Focus concept — starting point
2Refinement — attribute = value pairs
3Nesting — refine a value itself
Compositional grammar
Read the symbols
:separates focus concept from refinement
=links an attribute to its value
{ }groups attributes that belong together
,separates pairs in a group
| |human-readable term — the ID carries the meaning
