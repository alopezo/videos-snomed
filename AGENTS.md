# AGENTS.md

Guidance for AI coding agents (and humans) working in this repo.
See `README.md` for the user-facing overview.

## What this repo is

A code-only pipeline that turns an HTML scene file plus a narration script into a narrated vertical video (1080×1920, 30 fps).
**No media is committed.** `*.mp4`, `*.mp3`, `*.wav`, `*.png`, `audio/`, `music/` and `build/` are gitignored. Never add them, and never force-add them.

## Pipeline (run in this order)

1. `.venv/bin/python tts.py [voice] [speed]`: `narration.md` → `audio/scene_N.wav`. It prints each clip's length against its scene window. "OVER" is expected, because the next step stretches the scene.
2. `.venv/bin/python retime.py`: `index.base.html` + clip lengths → `index.html` + `build/timings.json`.
3. `node render.js "$(pwd)" "$(pwd)/build/video-silent.mp4"`: takes about 2.5 min for about 100 s of video.
4. `.venv/bin/python mix.py [music.mp3] [out.mp4]`: produces the final MP4 with voice, ducked music and −16 LUFS loudness.

Fast visual check, without rendering the whole video: `node render.js "$(pwd)" x 3,20,42` writes `../shot_N.png`.

## Rules of thumb

- **Edit `index.base.html`, not `index.html`.** `index.html` is regenerated by `retime.py` and any edits to it are lost.
- Scene boundaries come from the comments `<!-- S<n> <label> <start>-<end> -->` in `index.base.html`. Keep that format, with exactly one comment per scene, in order. The number of scenes must match the rows in `narration.md`.
- `narration.md` rows must keep the shape `| n | start–end | budget | text |`, because `tts.py` parses them with a regex.
- Write SNOMED CT terms in their real spelling in `narration.md`. Spoken-only fixes go in `PRONUNCIATION` in `tts.py`, using Kokoro's `[word](/ipa/)` syntax. Current fixes: SNOMED → /snˈOmˌɛd/ ("snow-med", with a clear *e*), FHIR → "Fire".
- To check a pronunciation without listening, print the phonemes with `KPipeline(lang_code="a").g2p(text)[0]`.
- Timing knobs live at the top of `retime.py` (`LEAD`, `FIRST_LEAD`, `TAIL`, `OUTRO`) and `mix.py` (`MUSIC_VOL`, `FADE_OUT`, `SILENCE_IN`, `SILENCE_OUT`). Don't hard-code timings elsewhere.
- Verify audio by measuring, not by guessing. Use `ffmpeg -af ebur128` for integrated loudness (target −16 LUFS), and `volumedetect` on short segments for silences and ducking. Music should sit about 8 dB under the voice when no one is speaking.
- Don't overwrite `postcoordination-explainer.mp4`, the original silent cut. The narrated output is `postcoordination-explainer-narrated.mp4`.

## Content accuracy

- Concept IDs and terms shown on screen must be real SNOMED CT concepts. Validate any new ones before adding them, for example against a Snowstorm/FHIR terminology server.
- Expressions must follow SNOMED CT compositional grammar.
- Cite the source guide on docs.snomed.org.

## Conventions

- Code, comments, commit messages and docs are in English.
- Python 3.10–3.12, using the `.venv` in the repo root. Node 18+, with Playwright from `package.json`.
- Keep scripts small, dependency-light and runnable from the repo root.
- Music must be royalty-free. Credit the track and its license in `README.md`, but don't commit the file.
