# videos-snomed

Short, vertical (1080×1920) explainer videos about SNOMED CT, built entirely from code:

- **Scenes** are a single HTML page per video, with time-coded animations.
- **Frames** are captured with Playwright and encoded with ffmpeg.
- **Narration** is generated locally with [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M), an open-weight TTS model.
- **Music** is a royalty-free background track, ducked under the voice and mixed with ffmpeg.

The repository holds only the logic. Rendered videos, generated audio and music files are ignored by git, so you rebuild them locally.

## Videos

| Folder | Topic | Length |
|--------|-------|--------|
| [`videos/postcoordination`](videos/postcoordination) | Precoordinated vs postcoordinated expressions, compositional grammar, use cases | ~98 s |

## Layout

```
build.sh            one-command build for a video
tts.py              narration.md → audio/scene_N.wav (Kokoro), shared pronunciation fixes
retime.py           stretches scenes to fit the narration → index.html + build/timings.json
render.js           index.html → silent MP4 (Playwright + ffmpeg), or single PNG frames
mix.py              voice + ducked music → final MP4, normalised to −16 LUFS
music/              shared local music library (gitignored)
videos/<name>/
  video.json        title, voice, speed, music track, output file name
  narration.md      narration script, one table row per scene
  index.base.html   scenes with their original timings (edit this one)
  index.html        generated by retime.py (committed so you can preview without building)
  audio/  build/    generated (gitignored)
```

The shared scripts take the video folder as an argument. Everything that differs between videos lives in `videos/<name>/`.

## Requirements

- Node 18+, Python 3.10–3.12, ffmpeg, espeak-ng

```bash
brew install ffmpeg espeak-ng
npm install && npx playwright install chromium
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

The first run of `tts.py` downloads the Kokoro model (~350 MB) from Hugging Face.

## Build

```bash
./build.sh postcoordination
```

This runs four steps, which you can also run one at a time:

```bash
.venv/bin/python tts.py videos/postcoordination            # [voice] [speed] override video.json
.venv/bin/python retime.py videos/postcoordination
node render.js videos/postcoordination videos/postcoordination/build/video-silent.mp4
.venv/bin/python mix.py videos/postcoordination
```

The result is written to `videos/<name>/<output>`, using the `output` name from `video.json`.

To preview single frames, which are saved as `videos/<name>/build/shot_N.png`:

```bash
node render.js videos/postcoordination x 3,20,42
```

You can also open `videos/<name>/index.html` in Chrome and run `render(20)` in the console to see second 20.

## Adding a new video

1. Create `videos/<name>/` with the four files: `video.json`, `narration.md`, `index.base.html` and `index.html`. The easiest way is to copy them from an existing video and adapt them.
2. In `index.base.html`, mark each scene with a comment `<!-- S<n> <label> <start>-<end> -->`.
3. Write one row per scene in `narration.md`, using the same scene numbers and times.
4. Pick a royalty-free track, put it in `music/` and credit it in the table above.
5. Run `./build.sh <name>`.

## Editing

- **Script:** edit `narration.md`, then rerun `./build.sh <name>`.
- **Scenes:** edit `index.base.html`, never `index.html`, which is overwritten. Each text is a `<div class="el">` with these attributes:
  - `data-s` / `data-e`: the second it enters and leaves.
  - `data-a`: the animation (`up`, `left`, `scale`, `type`).
  - `data-dur`: typing time, for `type` only.
  - `style="top:…px"`: vertical position on a 540×960 canvas.
- **Pronunciation:** the fixes are shared by all videos, in `PRONUNCIATION` in `tts.py`. Kokoro accepts explicit IPA as `[word](/ipa/)`. For example, SNOMED is read as *snow-med* and FHIR as *fire*.
- **Voice and speed:** set them in `video.json`. Any Kokoro voice works, for example `af_heart`, `am_michael` or `bf_emma`.
- **Pacing, silences and music level:** shared settings at the top of `retime.py` (`LEAD`, `FIRST_LEAD`, `TAIL`, `OUTRO`) and `mix.py` (`MUSIC_VOL`, `SILENCE_IN`, `SILENCE_OUT`).
