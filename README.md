# videos-snomed

Short, vertical (1080×1920) explainer videos about SNOMED CT, built entirely from code:

- **Scenes** are a single HTML page with time-coded animations.
- **Frames** are captured with Playwright and encoded with ffmpeg.
- **Narration** is generated locally with [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M), an open-weight TTS model.
- **Music** is a royalty-free background track, ducked under the voice and mixed with ffmpeg.

The repository holds only the logic. Rendered videos, generated audio and music files are ignored by git, so you rebuild them locally.

First video: **Postcoordination explainer**. It covers precoordinated vs postcoordinated expressions, compositional grammar and use cases, in about 98 seconds.

## How it works

```
narration.md ──tts.py──▶ audio/scene_N.wav ──┐
                                             ├─retime.py─▶ index.html + build/timings.json
index.base.html ─────────────────────────────┘                 │
                                                               ▼
                                     render.js ──▶ build/video-silent.mp4
                                                               │
            music/*.mp3 + audio/*.wav ──mix.py──▶ postcoordination-explainer-narrated.mp4
```

| File | Role |
|------|------|
| `index.base.html` | Source of truth for the scenes, with their original timings. |
| `index.html` | Generated by `retime.py`: each scene is stretched so its narration fits. |
| `narration.md` | Narration script, one table row per scene. |
| `tts.py` | Generates one WAV per scene with Kokoro. Also fixes pronunciation (see below). |
| `retime.py` | Measures each clip, stretches the scenes and writes `build/timings.json`. |
| `render.js` | Captures frames with Playwright and pipes them to ffmpeg. Can also save single frames as PNG. |
| `mix.py` | Lays the voice at scene timings, ducks and fades the music, normalises loudness to −16 LUFS and muxes it with the video. |

## Requirements

- Node 18+, Python 3.10–3.12, ffmpeg, espeak-ng

```bash
brew install ffmpeg espeak-ng
npm install && npx playwright install chromium
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

The first run of `tts.py` downloads the Kokoro model (~350 MB) from Hugging Face.

## Music

Music is not included. The postcoordination video uses
[“Corporate Background” by Kulakovka](https://pixabay.com/music/corporate-corporate-background-609167/)
under the [Pixabay Content License](https://pixabay.com/service/license-summary/).
Download it and save it as `music/kulakovka-corporate-background.mp3`. You can also pass any other track to `mix.py`.

## Build

```bash
.venv/bin/python tts.py af_heart 1.05      # voice + speed → audio/scene_N.wav
.venv/bin/python retime.py                 # → index.html, build/timings.json
node render.js "$(pwd)" "$(pwd)/build/video-silent.mp4"
.venv/bin/python mix.py                    # → postcoordination-explainer-narrated.mp4
```

Preview single frames (saved as `shot_N.png` in the parent folder):

```bash
node render.js "$(pwd)" x 3,20,42
```

You can also open `index.html` in Chrome and run `render(20)` in the console to see second 20.

## Editing

- **Script:** edit `narration.md`, then rerun the four build steps.
- **Scenes:** edit `index.base.html`, never `index.html`, which is overwritten. Each text is a `<div class="el">` with these attributes:
  - `data-s` / `data-e`: the second it enters and leaves.
  - `data-a`: the animation (`up`, `left`, `scale`, `type`).
  - `data-dur`: typing time, for `type` only.
  - `style="top:…px"`: vertical position on a 540×960 canvas.
- **Pronunciation:** add entries to `PRONUNCIATION` in `tts.py`. Kokoro accepts explicit IPA as `[word](/ipa/)`. For example, SNOMED is read as *snow-med* and FHIR as *fire*.
- **Pacing and silences:** `LEAD`, `FIRST_LEAD`, `TAIL` and `OUTRO` in `retime.py`, and `SILENCE_IN` / `SILENCE_OUT` in `mix.py`.
- **Music level:** `MUSIC_VOL` in `mix.py`.
- **Voice:** any Kokoro voice, for example `af_heart`, `am_michael` or `bf_emma`.
